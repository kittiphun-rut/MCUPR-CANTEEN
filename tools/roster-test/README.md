# ชุดทดสอบโปรโตคอลบัญชีสิทธิ์ (roster)

สคริปต์นี้ **ดึงฟังก์ชันจริงออกมาจากไฟล์ `.ino` ทั้งสองฝั่ง** แล้วคอมไพล์ด้วย `g++`
บนเครื่องพัฒนา เพื่อรันจำลองการคุยกันระหว่างแม่ข่ายกับสถานีทั้งวงจร
ไม่ได้คัดลอกโค้ดมาวางซ้ำ ถ้าแก้ตรรกะในสเก็ตช์แล้วพัง ชุดทดสอบนี้จะจับได้ทันที

## วิธีรัน

```sh
cd tools/roster-test
python3 extract.py      # ดึงโค้ดจาก .ino มาไว้ใน gen.inc
g++ -std=c++17 -Wall -Wextra -Wno-unused-parameter -Wno-unused-function -o rtest main.cpp
./rtest
```

ต้องมี `python3` กับ `g++` เท่านั้น ไม่ต้องใช้ toolchain ของ ESP32

## ครอบคลุมอะไรบ้าง

1. ผลักบัญชีชุดเต็มครั้งแรก (ตัดนิสิตที่ยังไม่ผูกบัตรออก)
2. ตัดสิทธิ์แล้วส่งอัปเดตทีละรายการ ไม่ผลักทั้งชุดใหม่
3. อัปเดตหายกลางทาง แล้วกู้คืนเองผ่าน heartbeat
4. สถานีทำเครื่องหมายเองตอนรับบัตรเข้าคิวออฟไลน์
5. ปิดยอดประจำวัน คืนสิทธิ์ทุกคน
6. บัญชีใหญ่เกินที่สถานีเก็บไหว (ต้องไม่ผลักชุดเต็มวนไม่จบ)
7. บัญชีค้างข้ามวัน — สถานะใช้สิทธิ์ของเมื่อวานต้องใช้ไม่ได้ แต่ยังปัดตกบัตรนอกทะเบียนได้
8. ค่าแฮชชนกันในชุดนิสิตจริง และผลแฮชสองฝั่งต้องเท่ากัน
9. เลขรุ่นวนรอบที่ 65535
10. heartbeat จากเฟิร์มแวร์สถานีรุ่นเก่าที่ไม่ได้ฝากเลขรุ่นมา

สคริปต์ยังตรวจด้วยว่านิยาม `RosterEntry` และ `HostRosterPacket` ในไฟล์ทั้งสองฝั่ง
ตรงกันทุกไบต์ ถ้าแก้ข้างเดียวจะฟ้องทันทีก่อนคอมไพล์
