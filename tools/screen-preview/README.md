# ตัวจำลองหน้าจอ TFT

วาดหน้าจอของทั้งสองฝั่งลงบนผืนผ้าใบในเบราว์เซอร์ ด้วยพรีมิทีฟชุดเดียวกับ
Adafruit GFX (`fillRect`, `drawRoundRect`, `setCursor`, ฟอนต์กว้าง 6 พิกเซลต่อขนาด 1)
ที่ความละเอียด 320x240 เท่าจอจริง

มีไว้ดูหน้าตาและตรวจว่าตัวอักษรไม่ล้นกรอบ **โดยไม่ต้องแฟลชลงบอร์ด**

> ⚠️ **นี่คือสำเนาที่เขียนตามโค้ดเฟิร์มแวร์ ไม่ใช่ตัวเฟิร์มแวร์เอง**
> ถ้าแก้หน้าจอใน `HostScreen.h` หรือ `StationScreen.h` แล้วไม่แก้ที่นี่ด้วย
> ภาพที่เห็นจะไม่ตรงกับของจริง **อย่าเชื่อภาพจากที่นี่แทนการทดสอบบนเครื่องจริง**

## ใช้อย่างไร

```sh
cd tools/screen-preview
python3 -m http.server 8099      # แล้วเปิด http://127.0.0.1:8099/tft.html
```

## ตรวจว่าการวาดบางส่วนไม่ทิ้งเศษพิกเซล

หน้าจอ MCU ไม่วาดใหม่ทั้งหน้าทุกครั้ง แต่วาดซ้ำเฉพาะช่องที่ค่าเปลี่ยน
ถ้าช่องที่ล้างเล็กกว่าตัวเลขเดิม จะเหลือเศษพิกเซลค้างบนจอ

`run_partial.mjs` ทดสอบให้อัตโนมัติ โดยวาดเต็มหน้าด้วยค่า ก. แล้วเทียบกับ
การวาดเต็มหน้าด้วยค่า ข. กับการวาดค่า ก. แล้วแก้เฉพาะช่องเป็นค่า ข.
**สองภาพต้องตรงกันทุกพิกเซล** ทดสอบทั้งโหมดมืดและโหมดสว่าง

```sh
cd tools/screen-preview
python3 -m http.server 8099 &
node run_partial.mjs
```

ตัวทดสอบนี้จับบั๊กจริงมาแล้ว: การเปลี่ยนป้าย ONLINE เป็น OFFLINE
ทิ้งสีเขียวค้างไว้ที่มุมโค้งทั้งสี่ของป้าย เพราะ `fillRoundRect` ไม่ได้ลงสีที่มุม
จึงต้องล้างกรอบสี่เหลี่ยมเต็ม ๆ ก่อนวาดป้ายใหม่
