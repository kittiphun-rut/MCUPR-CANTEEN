MCU Phrae Smart Canteen

ภาพหน้าจอระบบบริหารจัดการอาหารกลางวันนิสิต

รวมหน้าจอทั้งหมดของระบบคูปองอาหารดิจิทัล โควตา 35 บาท/คน/วัน ทั้งเว็บพอร์ทัลสำหรับเจ้าหน้าที่ จอเครื่องแม่ข่าย และจอเครื่องประจำร้านค้า สำหรับใช้ประกอบเอกสารโครงการและคู่มือการใช้งาน

Host Server v108.0.0 Station Client v118.0.0 ESP32-S3 N16R8 ST7789V 320×240 ESP-NOW CH 1 ภาพทั้งหมด 40 ภาพ
🖥️ เว็บพอร์ทัลเจ้าหน้าที่ 📟 จอเครื่องแม่ข่าย 💳 จอเครื่องประจำร้านค้า

🖥️ เว็บพอร์ทัลเจ้าหน้าที่

ภาพจากหน้าเว็บจริงที่เฟิร์มแวร์ส่งออกมา เปิดผ่าน http://192.168.4.1 หรือ http://canteen.local หลังเชื่อมต่อ Wi-Fi MCU_CANTEEN_HOST — ข้อมูลในภาพเป็นชุดตัวอย่างสำหรับสาธิต

📟 จอเครื่องแม่ข่าย (Host Server)

จอ ST7789V ขนาด 2.8 นิ้ว ความละเอียด 320×240 กดปุ่มหนึ่งครั้งเพื่อเปลี่ยนหน้า สองครั้งเข้าโหมดพักหน้าจอ สามครั้งสลับธีม และกดค้าง 5 วินาทีเพื่อดูหน้าเครดิต

💳 จอเครื่องประจำร้านค้า (Station Client)

เครื่องอ่านบัตร RFID ประจำแต่ละร้าน ทำงานร่วมกับแม่ข่ายผ่าน ESP-NOW ช่อง 1 นอกจากการเปลี่ยนหน้าแล้ว ยังกดค้าง 1.5 วินาทีเพื่อปิดไฟหน้าจอ และ 3 วินาทีเพื่อตั้งหมายเลขสถานี

หมายเหตุเรื่องที่มาของภาพ — ภาพเว็บพอร์ทัลถ่ายจากหน้าเว็บจริงที่เฟิร์มแวร์สร้างขึ้น ส่วนภาพจอ TFT สร้างขึ้นใหม่จากพิกัด สี และข้อความชุดเดียวกับที่อยู่ในฟังก์ชันวาดจอของเฟิร์มแวร์ (renderHostPage(), displayResult() และอื่น ๆ) จึงตรงตามเลย์เอาต์จริง แต่รูปทรงตัวอักษรจะต่างจากฟอนต์ 5×7 ของ Adafruit GFX บนอุปกรณ์จริงเล็กน้อย
