# ไฟล์วงจรสำหรับ KiCad

ไฟล์ในโฟลเดอร์นี้ **สร้างขึ้นอัตโนมัติ** จากผังขาในซอร์สของเฟิร์มแวร์
อย่าแก้ไฟล์ `.kicad_sch` ด้วยมือ เพราะจะถูกทับเมื่อสร้างใหม่

| ไฟล์ | คืออะไร |
|---|---|
| `Canteen_Host.kicad_pro` · `.kicad_sch` | วงจรของเครื่องแม่ข่าย เปิดด้วย KiCad ได้เลย |
| `Canteen_Station.kicad_pro` · `.kicad_sch` | วงจรของจุดบริการ |
| `MCUPR_Canteen.kicad_sym` | ไลบรารีสัญลักษณ์ เผื่ออยากเอาไปใช้ในงานอื่น |
| `*.net` | netlist ที่ KiCad เอ็กซ์พอร์ตออกมา ใช้ตรวจสอบและนำเข้า Pcbnew |
| `*.pdf` | ภาพวงจรสำหรับพิมพ์หรือส่งต่อ ไม่ต้องมี KiCad ก็เปิดดูได้ |
| `generate_kicad.py` | ตัวสร้างไฟล์ทั้งหมด |

## วิธีเปิด

ดับเบิลคลิก `Canteen_Station.kicad_pro` แล้วเปิดหน้า Schematic
**ไม่ต้องติดตั้งไลบรารีอะไรเพิ่ม** เพราะสัญลักษณ์ทุกตัวถูกฝังไว้ในไฟล์วงจรแล้ว
สร้างและทดสอบด้วย **KiCad 7** ส่วน KiCad 8 ขึ้นไปจะถามว่าจะอัปเกรดไฟล์หรือไม่ ตอบตกลงได้

## อ่านวงจรนี้อย่างไร

วงจรนี้ **ไม่ได้ลากเส้นยาวข้ามหน้า** แต่ใช้ **ป้ายชื่อเน็ต (global label)** แทน
ขาไหนที่มีป้ายชื่อเดียวกัน คือขาที่ต้องต่อถึงกัน เช่น ขา `GPIO14` ของบอร์ด
กับขา `SCL` ของจอ ต่างก็มีป้ายว่า `TFT_SCL` แปลว่าสองขานี้ต่อเข้าหากัน

วิธีนี้ตรงกับงานเดินสายจริงมากกว่าการลากเส้น เพราะสิ่งที่ช่างต้องรู้คือ
"ขานี้ไปขาไหน" ไม่ใช่ "เส้นวิ่งอ้อมทางไหน" และหน้ากระดาษก็ไม่รก

ขาที่มีเครื่องหมาย **✕** คือขาที่ตั้งใจไม่ต่ออะไร

## หมายเลขขาของบอร์ด ESP32-S3 DevKitC-1

สัญลักษณ์ `U1` นับขาแบบนี้ ให้หันด้านพอร์ต USB เข้าหาตัว

* **ขา 1 ถึง 22** คือแถวซ้าย ไล่จากบนลงล่าง เริ่มที่ `3V3` จบที่ `GND`
* **ขา 23 ถึง 44** คือแถวขวา ไล่จากบนลงล่าง เริ่มที่ `GND` จบที่ `GND`

เลขนี้ตรงกับตำแหน่งจริงบนบอร์ด และตรงกับตารางใน [`docs/HARDWARE.md`](../../docs/HARDWARE.md)

## รายการอุปกรณ์

| อ้างอิง | อุปกรณ์ | หมายเหตุ |
|---|---|---|
| `U1` | ESP32-S3 DevKitC-1 (N16R8) | 16 MB flash · 8 MB PSRAM แบบ OPI |
| `J2` | จอ ST7789 2.8" 320×240 | แปดขา ตรวจแรงดันก่อนจ่ายไฟ |
| `J3` (จุดบริการ) | MFRC522 13.56 MHz | ขา IRQ ไม่ได้ใช้ |
| `J3` (แม่ข่าย) | DS3231 ZS-042 | มีตัวต้านทานดึงขึ้น I2C บนโมดูลแล้ว ไม่ต้องใส่เพิ่ม |
| `J4` | ขั้วแบตเตอรี่ลิเธียม 1 เซลล์ | |
| `BZ1` | บัซเซอร์แบบพาสซีฟ | |
| `SW1` | สวิตช์กดติดปล่อยดับ | ใช้ตัวต้านทานดึงขึ้นภายในของชิป |
| `R1` `R2` | 100 kΩ 1% | วงจรแบ่งแรงดัน 1:2 สำหรับวัดแบตเตอรี่ |
| `C1` | 100 nF | กรองสัญญาณรบกวนที่จุดวัดแบตเตอรี่ |
| `C2` `C3` | 100 nF | กรองไฟเลี้ยงของโมดูล วางให้ชิดขาไฟของโมดูลที่สุด |

## สร้างไฟล์ใหม่และตรวจสอบ

```sh
python3 hardware/kicad/generate_kicad.py

cd hardware/kicad
kicad-cli sch export netlist --output Canteen_Host.net    Canteen_Host.kicad_sch
kicad-cli sch export netlist --output Canteen_Station.net Canteen_Station.kicad_sch
cd ../..

python3 tools/proto-check/kicadcheck.py
```

`kicadcheck.py` **ไม่ได้อ่านไฟล์วงจรตรง ๆ** แต่อ่าน netlist ที่ KiCad คำนวณออกมาเอง
แล้วเทียบกับค่าขาในซอร์สเฟิร์มแวร์ เท่ากับให้ KiCad เป็นคนยืนยันว่าเน็ตเชื่อมถึงกันจริง
จากนั้นตรวจสามข้อ

1. ทุกขาที่เฟิร์มแวร์ใช้ ต้องอยู่ในเน็ตชื่อเดียวกันในไฟล์วงจร
2. เน็ตสัญญาณต้องมีสองปลายพอดี ปลายเดียวคือลืมต่อ สามปลายคือชนกัน
3. ขา GPIO หนึ่งขาต้องไม่ไปโผล่อยู่สองเน็ต

## ข้อควรระวังก่อนลงมือประกอบ

* **แรงดันของจอ** จอ ST7789 บางรุ่นรับ 3.3V เท่านั้น ในวงจรต่อขา `VCC` ไว้ที่ `+3V3`
  ถ้าจอของท่านรับ 5V ได้และอยากใช้ 5V ให้ย้ายเอง **ตรวจสเปกก่อนจ่ายไฟทุกครั้ง**
* **บัซเซอร์ต่อตรงกับขา GPIO** ตามที่เครื่องต้นแบบใช้อยู่ ถ้าต้องการเสียงดังขึ้น
  ควรเพิ่มทรานซิสเตอร์ NPN กับตัวต้านทานฐาน แล้วให้ GPIO ขับฐานแทนการขับลำโพงตรง ๆ
* **วงจรแบ่งแรงดันกินไฟตลอดเวลา** ที่ 4.2V จะกินราว 21 µA ซึ่งน้อยมาก
  ถ้าต้องการประหยัดกว่านี้ให้เพิ่มมอสเฟตตัดวงจรตอนไม่ได้วัด
